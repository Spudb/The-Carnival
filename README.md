We made the hub and two games,
the hub contains the tents where you can access the games, currently the player is just a simple rectangle.    
The first game is "Treasure Hunt", where you search for the treasure.  
The second game is "Shooter", you have to shoot the targets in time and get a highscore.  
### The whole game is made by Godot engine, using gdscript.
## Treasure Hunt
It's a game where you have to get a shovel and start searching for the treasure in the whole map that has many different rooms.  
You move with WASD or with your arrow keys, and you interact with the "E" button.

## Shooter Game
A game where you have to shoot the most cans as you can in 30 seconds.  
You move with your mouse, and shoot with your left click.
